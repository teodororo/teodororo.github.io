este é um parágrafo simples. o texto flui normalmente, e você pode usar **negrito**, *itálico* e até ***os dois juntos***. links ficam assim: [exemplo](https://example.com).

## cabeçalho de segundo nível

h2 é o nível principal dentro de uma publicação — use para marcar uma mudança de assunto. não coloque h1 aqui dentro, o título da publicação já é o h1.

### cabeçalho de terceiro nível

para subdivisões dentro de uma seção. não precisa ir além disso.

## listas

sem ordem:

- primeiro item
- segundo item, com um pouco mais de texto só para ver como se comporta
- terceiro item

com ordem:

1. primeiro passo
2. segundo passo
3. terceiro passo

## citação em bloco

> uma frase que você quer destacar. pode ter mais de uma linha, e vai aparecer recuada na margem com um traço ao lado.
>
> segundo parágrafo da citação.

## código

inline: `variavel = "valor"`. e em bloco:

```python
def oi(nome):
    return f"olá, {nome}"
```

também funciona com outras linguagens:

```bash
git add -p && git commit
```
